Policies, processes and documents

A policy can live in Keen, as an uploaded file, or in another document system. Either way Keen keeps a document record that gives it a title, type, folder, tags and links to controls and clauses, so it takes part in the management system. This chapter shows the three content modes and how history is kept.

Organise documents and preserve their history

ISMS → Policies & processes holds the documents and the folders they are filed in. The Folders panel beside the table works like a file manager: choose a folder to list what is filed in it, All documents to list everything with each document's folder path, or Unfiled for documents in no folder. The path above the table shows where you are, and each folder in it opens that folder. Open a document to read it, its revisions, its comments and its changelog.

  1. Create folders where they belong: open the parent folder and choose New folder, type the name and press Enter. A simple structure such as Governance, People, Operations and Reviews works well; control links connect material across it. Folder names are unique within their parent.
  2. Create a document with a title, type, folder and tags, and a short description of its purpose. Link the relevant controls and clauses.
  3. Choose the content mode: Write in Keen, Upload a file or Link to a URL.
  4. Save, reopen and read the actual content. Check an uploaded file is the right one; use headings and lists in written text so responsibilities and procedures are easy to find.
  5. For text written in Keen, each save of changed content creates a numbered revision. Open the document's Revisions tab to preview earlier content and its checksum.
  6. Use folders, types and coloured tags to keep current material findable, and check links after moving a document.

Arrange folders and move documents

Anyone who manages the ISMS can rearrange the tree. Drag a document row onto a folder to file it there, or onto Unfiled to take it out of every folder. Drag a folder onto another folder to nest it, or onto All documents to move it to the top level; a folder cannot move into one of its own folders. The Move button in a document's actions, and Move folder in the panel's toolbar, choose the destination from a list instead.

The tree works from the keyboard too. The arrow keys move between folders and open or close them, Home and End go to the first and last, Enter opens a folder, F2 renames it and Delete deletes it. Rename folder edits the name in place: Enter saves it and Escape keeps the old one. Only an empty folder can be deleted, so move its documents and folders out first. Moving a document is recorded in its changelog.

What is versioned. Native text has revision history. File uploads and external URLs do not: a replacement upload changes the current file, and an external page can change at any time. When you must prove which version was reviewed, keep an explicitly versioned record or a captured audit artefact.

Comments are for discussion; a comment is not an approved revision. Record staff acknowledgement of a policy in People assurance records with the supporting evidence. If someone else saved first, Keen refuses the stale save: copy your text somewhere safe, reload and reconcile.

Write, upload and link policies and procedures

The record is separate from the content it refers to, which is what lets the three modes coexist. Pick the one that matches where the text is maintained.

Write a policy directly in Keen

  1. In ISMS → Policies & processes, create a document with a meaningful title, type, purpose, folder and tags.
  2. Select Write in Keen and write in the editor. For a policy, a useful structure is purpose, scope, responsibilities, requirements and review arrangements.
  3. Select the relevant clauses and controls, save, and open the document detail to check the rendered text and relationships.
  4. To continue writing, open the document and choose Edit document, change the text and save.
  5. Open a version on the document's Revisions tab to read its saved content and SHA-256 checksum. Choosing an old version shows a preview and leaves the current document unchanged.
  6. Use the Comments tab for discussion, and record formal approval the way your organisation's review process requires.

Upload an existing document

Select Upload a file, choose the file and save. Open the saved detail page to check the filename, uploader, upload time and the downloadable file; Keen records the stored file's size and checksum. Files up to 100 MiB are accepted, and the supplied nginx configuration allows the same; another reverse proxy may impose a smaller limit.

Link a document maintained elsewhere

Select Link to a URL and enter the address, then add the title, description and control and clause links as for any document. Check the URL with an account typical of its intended readers, who also need permission in the external system.

Going deeper: BookStack and switching content modes

When the BookStack ingester is enabled, ISMS → Policies & processes → BookStack pages & sections lets you select a page or section, associate it with an ISMS document and a control or clause, and keep a snapshot as audit evidence. Document management permissions govern capture; readers can review retained snapshots.

The content selector controls what you edit. When you switch a record between native text, upload and link, check the saved detail: the record can keep file metadata from an earlier upload.
