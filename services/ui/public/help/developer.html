Developing Keen

This guide explains the code paths behind Keen's framework, evidence, risk and assurance workflows, for people changing the application. It accompanies Using Keen and Administering Keen. Each chapter names the modules that own a behaviour and the invariants a change must keep; paths are relative to the Keen repository unless another project is named.
