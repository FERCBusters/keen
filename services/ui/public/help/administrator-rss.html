RSS feeds

RSS: one source per feed

In Sources & Evidence Mapping, choose Define a source → RSS. Enter a source name, the full feed URL and any optional authentication or headers. Saving the source configures its feed. Choose Collect now to fetch evidence or Add mapping rule to link it to controls. RSS has no separate input setup step.

Each feed has its own credentials and collection progress. Use Edit source to change its feed URL or credentials. Credentials are restricted to the feed server’s origin. Create another RSS source for another feed. File-managed sources and existing sources containing multiple feeds retain their configured inputs.
