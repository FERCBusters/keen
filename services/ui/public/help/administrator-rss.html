RSS feeds

An RSS or Atom feed is the simplest source: one source per feed, no separate input step.

RSS: one source per feed

  1. In Sources & evidence mapping, choose Define a source → RSS.
  2. Enter a source name, the full feed URL and any optional authentication or headers. Saving the source configures its feed.
  3. Choose Collect now to fetch evidence or Add mapping rule to link it to controls.

Each feed has its own credentials and collection progress; create another RSS source for another feed. Use Edit source to change its URL or credentials, which are restricted to the feed server's origin. File-managed sources and existing sources containing multiple feeds retain their configured inputs.
