Google Workspace

Google Workspace collection reads admin report streams through a delegated service account, so sign-ins, sharing and administrative changes can stand as evidence.

SettingPurpose
KEEN_GOOGLE_WORKSPACE_ENABLEDTurns the adapter on.
GOOGLE_WORKSPACE_IMPERSONATEThe delegated administrator identity.
GOOGLE_WORKSPACE_SA_KEYFILE, GOOGLE_WORKSPACE_SA_JSON or GOOGLE_WORKSPACE_SA_JSON_B64The service-account material. A keyfile path must exist inside the running container.

Grant the required upstream scopes and delegation deliberately, and keep private-key material out of collection definitions and browser-visible settings. Add named report streams under streams with the application, user key and system to query. The retained payload is under google_workspace; the upstream report application and event type determine its content.

Posture on the vendor page

Google Workspace posture reads the users of the delegated administrator's own customer, with the same service account and GOOGLE_WORKSPACE_IMPERSONATE, and shows them on the Google Workspace vendor's Cloud posture tab (see Cloud vendor posture). Set KEEN_GOOGLE_WORKSPACE_POSTURE_ENABLED and add https://www.googleapis.com/auth/admin.directory.user.readonly to the service account's domain-wide delegation in the Admin console, under Security → Access and data control → API controls → Manage domain-wide delegation. The report streams above provide the vendor page's recent activity.

Suspended and archived users are left out. Every user the listing returns must belong to one customer; otherwise the refresh reads not set up.

Inspect and map evidence

Inspect a collected event and use Create mapping from this event. Structured selectors expose the payload that this source actually returns; a useful starting path is google_workspace. Action and outcome filters use Keen's normalised event values. Preview matching and non-matching examples.

For file-managed deployments, collection inputs live in config/google_workspace.yml. See the common collection workflow for UI configuration and override behaviour.
