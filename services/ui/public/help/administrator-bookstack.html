BookStack

BookStack uses KEEN_BOOKSTACK_ENABLED, KEEN_BOOKSTACK_BASE_URL, BOOKSTACK_TOKEN_ID and BOOKSTACK_TOKEN_SECRET. Browse the server-backed book/page catalogue in the editor. Choose pages and configure capture options through the supported settings. Imported selectors can continue to identify pages by book, slug, title or pattern. Check captured content and section handling before relying on a policy extract as evidence.

BookStack content selection is also available through Policies & Processes when the ingester is enabled. Choose the required document or page elements, then inspect the captured content before linking it to controls.

Payloads include bookstack → page_id, page_slug, page_title, book_slug and preview information. Select the actual nested JSON path shown on the event.

Inspect and map evidence

Inspect a collected event and use Create mapping from this event. Structured selectors expose the payload that this source actually returns; a useful starting path is bookstack → page_slug. Action and outcome filters use KEEN’s normalised event values. Preview matching and non-matching examples.

For file-managed deployments, collection inputs live in config/bookstack.yml. See the common collection workflow for UI configuration and override behaviour.
