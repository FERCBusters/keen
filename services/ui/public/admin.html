Evidence retention

Manage collected events across all sources and frameworks. Audit-sampled events and their stored files remain protected until every audit holding them is deleted.

Automatic retention

Disabled by default. Cleanup runs in the background using the KEEN worker and scheduler.

Purge all collected evidence

Delete all eligible events up to the time you start the purge, including event mappings, attached files, event questions and incident links. Audit-protected evidence is kept. Frameworks, mapping rules, source configuration, ISMS records and the administrative audit trail remain.

All ingesters, agents and webhook intake pause automatically while a manual purge is queued or running and for five minutes after completion or cancellation. In-flight database work drains before deletion. Your existing source pause settings are preserved. Upstream systems may send previously deleted events again after ingestion resumes.

Cleanup status

Manage audits

S3 retention locks and legal holds are respected. Stored files awaiting deletion stay in the cleanup queue and retry automatically. Removing a sample from an audit does not release its retention protection; delete the audit to release it.

Advanced match patterns (regex)

Patterns match text within a field. Preview against real evidence before saving.

How to write a regex pattern

KEEN uses Python regular expressions. A pattern searches anywhere in the field and is case-sensitive by default. Enter the pattern directly, without surrounding slashes. Leave it empty to allow every value.

  • ^ anchors the beginning; $ anchors the end.
  • \. matches a literal dot. A plain . matches any character except a newline.
  • | means “or”; (?:...) groups alternatives.
  • Put (?i) at the beginning to ignore capitalisation.
Example patterns for mapping filters
FilterPatternMatches
Action regex^package\.Actions beginning with package., including package.status and package.upgrade
Action regex^package\.(?:install|upgrade)$package.install or package.upgrade
Summary regex(?i)\b(?:error|failed)\bThe whole word error or failed, with any capitalisation

All populated filters are combined with AND, including an exact filter and its regex. To allow several actions, leave the exact Action filter empty and use alternatives in Action regex. Structured field conditions also combine with AND and use their own selected operators.

Patterns may contain up to 512 characters. KEEN rejects invalid syntax and restricted constructions, including backreferences, nested repetitions such as (a+)+, and repeated alternatives. Keep patterns simple and check both matching and non-matching events in Preview.

Type a single backslash in this form. In a YAML file, single quotes preserve it: action_regex: '^package\.'. JSON strings need doubled backslashes: "action_regex": "^package\\.".

Use a meaningful name. Control suggestions use this text; change it and request suggestions again to explore other matches.
