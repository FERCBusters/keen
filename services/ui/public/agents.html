Installation, configuration and evidence mapping

Build the standalone Go agent from the keen-agent directory and follow its README and systemd installation instructions. The supplied service runs as a dedicated user. Grant read access to the selected logs and their rotated successors.

OTLP logs endpoint:

Save the credential in /etc/keen-agent/token with mode 0640, owned by root:keen-agent. It is omitted from the configuration download.

Events appear with source KEEN Agent and the registered name as their system. In Sources & evidence mapping, match source = keen-agent and the required action, outcome or normalized payload fields, then select the relevant framework controls.
